## 第二部分：实习篇（面向2026届/2027届在校生）

> **当前状态说明**：
> 1. **日常实习**：全年开放，适合大二、大三、研一同学积累经验，面试流程快，**现在即可投递**。
> 2. **暑期实习（转正）**：通常在**3月-4月**开启，含金量最高，是2026届毕业生拿校招Offer的黄金跳板。
